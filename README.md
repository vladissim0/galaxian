# Galaxian — Browser Game

A simple browser-based space shooter built with **HTML, CSS, and JavaScript**.

## About the Game

Galaxian is a small arcade-style game where the player controls a spaceship and shoots enemies before they reach the bottom of the game field.

## Features

- Move the spaceship left and right.
- Shoot lasers at enemies.
- Enemies move down the game field.
- Detect collisions between lasers and enemies.
- Earn points for destroying enemies.
- Game Over when enemies reach the bottom.
- Start the game using the Start button.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## How to Play

1. Open the game in your browser.
2. Click the **Start** button.
3. Use the **Left Arrow** and **Right Arrow** keys to move the spaceship.
4. Press **Spacebar** to shoot lasers.
5. Destroy enemies and earn points.
6. Try to prevent enemies from reaching the bottom of the game field.
